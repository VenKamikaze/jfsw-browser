# Lesser bugs in the original game

Bugs found in upstream jfsw, jfbuild or jfaudiolib (at the pinned commits) while doing the browser work that **don't break the game**, or that break it only **in a feature a normal multiplayer game is unlikely to use** (marked **not planned**). Game-breaking, reproducible bugs get their own fix brief instead (see "Bugs found in the original game" in [`README.md`](README.md)). Nothing here has been sent upstream.

Each entry: where, what happens, how it was found, and its state (**open**, **worked around** in a brief, **fixed** on a `fix/` branch, or **not planned**).
